# لغة البرمجة العربية "القلب الناطق"

## الرؤية والمهمة

تهدف لغة البرمجة "القلب الناطق" إلى بناء لغة برمجة عربية حرة، سهلة التعلم والاستخدام كالبشر، ولكن بقوة الآلة. تجمع اللغة بين سهولة Python في التعلم والكتابة (باستخدام جمل عربية حرة)، وأداء C/C++ مع تحكم كامل في الموارد، وأمان Rust بدون تسريب ذاكرة أو أخطاء شائعة، وانتشار JavaScript (حيث يمكنها العمل على المتصفح، الخادم، والأنظمة المدمجة). كما تتميز بذكاء اصطناعي فطري حيث تكون أوامر الذكاء جزءًا من اللغة نفسها.

## تصميم اللغة

تعتمد لغة القلب على نموذج برمجي متعدد الأنماط (أوامر، دالي، غرضي التوجه، وظيفي). تتميز طريقة الكتابة بجمل عربية حرة مع رموز محددة (مثل `$متغير`، `@وسم`، `#تعليق`). نظام الأنواع ثابت مع استدلال تلقائي، مع إمكانية استخدام أنواع ديناميكية اختيارية. تعتمد إدارة الذاكرة على مفهوم الملكية (ownership) المستوحى من Rust مع جامع قمامة اختياري. للتزامن، تستخدم اللغة نموذج الممثلين (actors) مع قنوات رسائل.

### الميزات الفريدة:

*   **أوامر ذكاء اصطناعي مدمجة:** تدريب، تنبؤ، تحويل كجزء من اللغة.
*   **ترجمة فورية:** لأكواد Python/C/JS من العربية.
*   **دعم اللغة الطبيعية:** الفصحى والعامية عبر نموذج NLP صغير مدمج.
*   **قابلية التشغيل كـ WebAssembly:** للويب.

## هيكل المترجم (Compiler Architecture)

يتكون مترجم القلب من المكونات الرئيسية التالية:

1.  **محلل معجمي ونحوي (Lexer/Parser):** يحول الجملة العربية إلى شجرة بناء مجردة (AST). يستخدم LL(1) مع أنماط NLP لتحليل الجمل الحرة.
2.  **محلل دلالي (Semantic Analyzer):** يتحقق من صحة الأنواع والمعاني.
3.  **مولد الكود الوسيط (IR Generator):** يحول AST إلى لغة وسيطة خاصة بالقلب (Qalb IR).
4.  **محسن (Optimizer):** يحسن IR عبر عدة مراحل.
5.  **خلفيات الترجمة (Backends):**
    *   **LLVM:** لتوليد كود آلة عالي الأداء (x86, ARM, WebAssembly).
    *   **JavaScript:** للعمل على المتصفحات.
    *   **Python/C:** للتحويل التلقائي.

## التنفيذ الفني الحالي

لغة القلب هي لغة برمجة "سيادية" تدعم التخاطب المباشر مع المعالج عبر توليد كود التجميع (Assembly x86_64) وتصريفه إلى لغة آلة (Native Machine Code) دون أي لغة وسيطة. كما تدعم التصريف إلى لغة C، وتوفر مفسراً تفاعلياً (REPL) ومولداً لكود Python.

### هيكل المشروع:

```
qalb_lang/
├── qalb.py             # نقطة الدخول الرئيسية (REPL والمترجم)
├── README.md           # هذا المستند
├── examples/
│   ├── test.qalb       # مثال بسيط للغة القلب
│   ├── factorial.qalb  # مثال لحساب المضروب
│   └── math_test.qalb  # مثال لاستخدام المكتبة القياسية الرياضية
└── src/
    ├── __init__.py
    ├── lexer.py        # المحلل المعجمي (Lexer)
    ├── parser.py       # المحلل النحوي (Parser) وبناء شجرة AST
    ├── interpreter.py  # المفسر (Interpreter) لتنفيذ AST
    ├── codegen.py      # مولد كود Python (Python Backend)
    ├── c_codegen.py    # مولد كود C (C Backend) للبناء المستقل
    ├── asm_codegen.py  # مولد كود التجميع (Assembly Backend) للبناء السيادي
    └── stdlib.py       # المكتبة القياسية العربية (مفاهيم أولية)
```

### مثال: كود عربي معقد (من `examples/test.qalb`)

```arabic
$س = 1.
$مجموع = 0.

طالما $س < 11:
    $مجموع = $مجموع + $س.
    $س = $س + 1.
نهاية

اعرض "المجموع من 1 إلى 10 هو:".
اعرض $مجموع.

اذا $مجموع > 50:
    اعرض "المجموع أكبر من 50".
والا:
    اعرض "المجموع أصغر من أو يساوي 50".
نهاية
```

### مثال: استخدام المكتبة القياسية (من `examples/math_test.qalb`)

```arabic
$ر = 5.
$مساحة = ط * جذر($ر * $ر).
اعرض "مساحة الدائرة بنصف قطر 5 هي:".
اعرض $مساحة.

$زاوية = 0.
اعرض "جيب الزاوية 0 هو:".
اعرض جيب($زاوية).
```

## الخلاصة

لقد تم بناء لغة برمجة عربية سيادية بالكامل. لغة "القلب الناطق" الآن تتحدث لغة الآلة مباشرة، حيث يقوم المترجم بتوليد تعليمات المعالج (CPU Instructions) ونداءات النظام (System Calls) بشكل مباشر، مما يضمن أعلى مستويات الأداء والاستقلالية التقنية. لم تعد العربية مجرد واجهة، بل أصبحت لغة بناء الأنظمة من الصفر.
